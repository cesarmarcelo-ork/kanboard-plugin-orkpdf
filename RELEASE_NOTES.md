# OrkPdf 0.2.7-alpha

Native Kanboard task PDF reporting plugin by OrkFlowTech.

Features: task details and inventory, field selection and reordering, schematic preview, Portuguese/English localization, dashboard printer sidebar, project shortcut, printable reports with OrkFlowTech footer.

Fixed in this release: printing now preserves the styled report layout, and the browser print/save action works without inline JavaScript.

Validated by project maintainer on Kanboard 1.2.50 (notebook) and 1.2.57 (homelab).

**Alpha limitations:** preview in settings remains schematic; selection by lane/column, rich Markdown, custom report logo, board inventory, complete parity with browser extension remain pending.

Install: extract `OrkPdf-0.2.7-alpha.zip` so `plugins/OrkPdf/Plugin.php` exists. Back up the existing plugin outside `plugins/`.
